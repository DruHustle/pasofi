# PamoFi mobile frontend

This independent React/Capacitor project contains the iPhone and Android apps. Node.js 22 or newer is required.

The app is an **offline preview** with example bundles and help. It does not create accounts, take payments, recover access, or connect customers to Wi-Fi. Prices are illustrative and are not live offers. The current backend relies on browser-origin checks and same-site session cookies; secure mobile authentication and a mobile API are required before this app can operate as a prepaid Wi-Fi service.

```sh
npm ci
npm test
npm run mobile:sync     # build the app and copy assets into native projects
npm run mobile:ios      # open Xcode on macOS
npm run mobile:android  # open Android Studio
```

For iPhone, install Xcode and an iOS simulator runtime, accept Apple's Xcode license, select a simulator, and run the app. A signed build for a physical iPhone or App Store distribution requires an Apple Developer team and signing configuration. The app icon is provisional; its editable vector is in `assets/app-icon.svg`. The bundle ID `com.onesa.pamofi` is provisional and must be confirmed before registration.

For Android, install Android Studio and its SDK, select a compatible JDK 21 for Gradle, and install Android SDK Platform 36. Android Studio builds that bundle JDK 25 are too new for Gradle 8.14. Run on an emulator or device; a signed release requires an owner-controlled signing key, which must never be committed.

After changing React or Capacitor configuration, run `npm run mobile:sync` before rebuilding native projects. Native web assets and generated Capacitor configuration are ignored by Git and regenerated by that command. Never point the production WebView at a remote development server.

Browser checks cover the preview layout and offline behavior, but do not replace native emulator/device testing. Start the mobile development server and run `PAMOFI_CHROME_PATH=/path/to/chrome npm run test:browser`. Set `PAMOFI_BASE_URL` if it is not listening at `http://localhost:5173`.
