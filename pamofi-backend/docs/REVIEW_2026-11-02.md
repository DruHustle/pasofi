## Reproduce and assess release readiness

Use [TESTING.md](TESTING.md) and `local-tools/verify.mjs --integration --browser`. The runner rejects missing databases or skipped cases, uses dynamic loopback ports and stops only its own child processes. Read the exact pull request's workflow outcome for PostgreSQL 17.11 and the FreeRADIUS/backup/staging container checks; the local results above do not substitute for those results.

This review does not establish a working commercial hotspot. [BUILD_STATUS.md](BUILD_STATUS.md) lists unfinished staff/agent flows, private receipts, live provider qualification, network termination/reconciliation, production operations and independent backup configuration. Browser tests of the mobile preview and native sync do not certify an iOS/Android build or device behavior.
